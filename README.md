# Portfolio Iso

Welcome to the **Portfolio Iso** project!

## Description
This project is a personal portfolio developed in HTML, CSS, and JavaScript. It showcases Iso's skills, projects, and contact information.

## Project Structure
- `index.html`: Main page of the portfolio
- `style.css`: Stylesheet for the site's design
- `script.js`: JavaScript logic for interactivity
- `SPEC.md`: Functional and technical specifications of the project

## Installation
No installation is required. Simply open the `index.html` file in your preferred web browser.

## Usage
1. Clone the repository or download the files.
2. Open `index.html` in a browser.
3. Browse through the different sections of the portfolio.
